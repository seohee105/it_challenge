## 2. 칼로리 정확도 & 그램 보정 효과 (실측 대조)

### 그램 보정(×0.88) 전후 — out-of-sample 검증
| 데이터셋 | 지표 | 보정 OFF (1.0) | 보정 ON (0.88) |
|---|---|:--:|:--:|
| **sf45_diverse** (단품 11장, held-out) | MAPE | 33% | **24%** |
| | ±25% 이내 | 55% | **64%** |
| | ±50% 이내 | 73% | **91%** |
| | 과다추정 | +29% | **+13%** |
| **n5k2** (혼합접시 15장) | MAPE | 42% | 40% |
| | ±25% 이내 | **47%** | 33% |
| | ±50% 이내 | 60% | 73% |
| | 추정 vs 실측 | 280 vs 311 (**−10%**) | 240 vs 311 (**−23%**) |

> 보정계수 0.88은 별도 SF45 20장에서 도출 → 위 sf45_diverse·n5k2는 **도출에 쓰지 않은 held-out**.
> **⚠️ 중요 뉘앙스 — 보정은 단품엔 이득, 혼합접시엔 손해:**
> - **단품**(sf45_diverse)은 +29% **과다**추정 → 0.88 보정이 MAPE 33→24%로 개선 ✅
> - **혼합접시**(n5k2)는 오히려 −10% **과소**추정 → 0.88이 −23%로 **더 나빠짐**(±25% 47→33%) ❌
> - 원인: +12~16% 과다 편향은 **단품에서만** 성립. 혼합접시는 합산/구성 특성이 달라 편향 방향이 반대.
> - 시사점: **전역 0.88은 단품에 최적**. 혼합접시엔 보정을 약하게/끄거나 별도 처리 필요.
> - **해결 완료(아래 참고):** 보정을 단품(음식 1개)에만 적용하도록 스코프 + 혼합접시는 홀리스틱으로.

### 혼합접시 개선 — 보정 스코프 + 홀리스틱 확대 (해결)
| 처리 | 대상 | 결과 |
|---|---|---|
| 그램 보정을 **단품에만** 적용 | 음식 1개 | 단품 이득 유지(스코프 후 sf45_diverse MAPE 21%·±25% 73%), 혼합접시 역효과 제거 |
| **다중음식 홀리스틱** 기본 발동 | 음식 2개+ | 혼합접시 A/B(Nutrition5k, 평균재료11.7개): 합산 MAPE28%/±25%53%/**r0.36** → 홀리스틱 MAPE24%/±25%64%/**r0.70** |

> 혼합접시 과소추정의 정체는 **항목 누락(커버리지)** → 접시 전체를 통으로 보는 홀리스틱이 실제 총량을 훨씬 잘 추종(상관 거의 2배). 단품은 미발동이라 영향 없음. 대가는 다중음식 접시당 API 1회 추가.

- 한식 칼로리의 진짜 레버 = **분산 축소 = 스케일 앵커**.

## 7. 스케일 앵커 (도메인 무관 — 물리 측정)
동전(24mm)·숟가락 기준물로 실제 크기를 재는 방식. AI Hub 데이터는 전 사진에 기준물 박스 존재.

| 근거 | 실제 양과 상관 r |
|---|:--:|
| Gemini 현재(앵커 없음) | 0.47 |
| 기하학적 천장(라벨 동전박스, 145쌍) | 0.65 |
| 프롬프트 스케일앵커(부분 18장) | 0.66 |

→ **스케일 앵커가 상관을 천장까지 끌어올림(0.47→0.66)** — 강력하나 부분실행이라 깨끗한 재검 필요(보류).
※ 그램앵커=도메인 의존(한식≠양식)이라 bi-cuisine 확장, 스케일앵커=도메인 무관(한 번 되면 양쪽).
