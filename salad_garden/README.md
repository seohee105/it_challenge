# 샐러드 가든 - Godot 4.7 프로토타입

설계도(`전체_맵_설계도.png`, `saladgarden2.png`)를 기반으로 만든 **플레이 가능한 코어 시스템 프로토타입**입니다.
지금은 실제 픽셀아트 대신 **색깔 사각형(플레이스홀더)**으로 동작을 확인할 수 있게 되어 있습니다.

## 여는 방법
1. Godot 4.7을 실행 → "Import" → 이 폴더(`salad_garden`)의 `project.godot` 선택
2. F5 또는 실행 버튼으로 플레이 (메인 메뉴 → 게임 시작 → 데모 레벨 → 보스전)

## 조작
- 이동: ← → 또는 A / D
- 점프: Space 또는 ↑

## 구현된 시스템 (요청하신 6가지 조건 반영)
1. **Godot 4.7 프로젝트**로 구성 (`config/features = "4.7"`)
2. **던전(레벨) 입장** 구조: MainMenu → Level1(플랫포머) → BossRoom(보스전)
3. **점프로 적 회피** 가능 (일반 CharacterBody2D 물리 + 점프)
4. **적에 닿으면 게이지 감소** (`GameManager.take_damage()`), 화면 상단 게이지 바로 표시
5. **플랫포머 → 보스전 흐름**
   - ♥️ 하트 획득 → 게이지 최대치/현재치 증가 (플레이 가능 시간 ↑)
   - 🗡️ 공격 아이템 획득 → 적과 부딪히면 적을 처치
   - 🛡️ 방어 아이템 획득 → 적과 부딪혀도 방어막 1개 소모하고 피해 없이 통과
   - 게이지가 0이 되면 보스전 입장 불가 → 게임오버 화면으로 이동
   - 보스는 머리 위 약점을 밟거나(스톰프), 공격 아이템 보유 시 몸통에 닿아서 처치
6. **필요한 이미지 에셋** (아래 목록) — 지금은 없어서 색깔 사각형으로 대체 중

## 핵심 스크립트
- `autoload/GameManager.gd` : 게이지/공격/방어/코인 전역 상태 (오토로드 싱글톤)
- `scripts/Player.gd` : 이동, 점프, 피격/아이템 상호작용
- `scripts/Enemy.gd` : 일반 몬스터(토마토/브로콜리/당근/옥수수 등) 공용 왕복 이동
- `scripts/Item.gd` : 하트/공격/방어/코인 픽업
- `scripts/Boss.gd` : 보스(수확 로봇) 이동 + 약점 스톰프 + 즉시처치
- `scripts/LevelExit.gd` : 플랫포머 구간 끝 → 보스전 or 게임오버 분기

## 지금 데모에 들어있는 구간
설계도의 **① 시작 구간 + ② 토마토 밭** 일부를 데모로 구현했고, 곧바로 **⑨ 보스 구간**으로 연결됩니다.
③~⑧ 구간(브로콜리 숲, 당근 언덕, 옥수수 농장, 샐러드 호수, 아보카도 마을, 비밀 온실)은
동일한 패턴(Ground + Platform + Enemy + Item + LevelExit)으로 `Level1.tscn`을 복제/확장하거나
씬을 이어붙이면 됩니다. 구조가 이미 갖춰져 있어서 실제 타일 이미지만 있으면 빠르게 채울 수 있습니다.

## 🎨 제작을 위해 필요한 이미지 에셋 목록

설계도의 "사용 타일" / "타일 확대" / "컬러 팔레트" 섹션을 기준으로 정리했습니다.
**32x32px 픽셀아트 스타일**, 배경은 5레이어(하늘/먼 산/중간 배경/가까운 소품/지면) 구성입니다.

### 1) 캐릭터 스프라이트시트
- 플레이어 캐릭터: 대기/걷기/점프/피격 애니메이션 (예: 32x48px 기준 스프라이트시트)

### 2) 타일셋 (32x32px)
- 기본 블록, 높은 블록, 모서리 블록, 계단 블록, 사다리 블록
- 파이프(초록/연핑/연결), 나무 울타리, 발 울타리, 잔디 블록, 돌 블록

### 3) 몬스터 스프라이트 (구간별)
- 🍅 토마토 몬스터 (2구간)
- 🥦 브로콜리 몬스터 (3구간)
- 🥕 당근 몬스터 (4구간)
- 🌽 옥수수 몬스터 (5구간)
- 👹 보스 "수확 로봇" (9구간, 대형 + 약점 부위 구분되면 좋음)

### 4) 배경/오브젝트
- 아보카도 집, 분수, 온실, 상점/포장마차 (6~8구간 배경 오브젝트)
- 배경 5레이어: ① 하늘/구름 ② 먼 산/언덕 ③ 중간 배경(숲/가든) ④ 가까운 소품(화분,올타리,표지판,벤치) ⑤ 지면/플랫폼 타일

### 5) UI / 아이템 아이콘
- 코인 아이콘 🪙
- ♥️ 생명력(하트) 아이템 아이콘
- 🗡️ 공격 아이템 아이콘
- 🛡️ 방어 아이템 아이콘
- 게이지 바 프레임 (선택)

이 이미지들을 만들어서 올려주시면, 지금 만든 `Item.gd`, `Enemy.gd`, `Player.gd`, `Boss.gd`의
`ColorRect` 플레이스홀더를 `Sprite2D`/`AnimatedSprite2D`로 교체하고, TileSet 리소스를 만들어서
9개 구간 전체를 설계도 그대로 채워드릴 수 있습니다.
